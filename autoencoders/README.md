# Autoencoders and Discrete Representations

[Back to portfolio](../README.md)

## [Autoencoders](01_autoencoders.ipynb)

Linear and convolutional autoencoders, MNIST reconstruction, latent-space visualization and PCA comparisons.

## [Variational Autoencoders](02_variational_autoencoders.ipynb)

Reparameterization, reconstruction and KL losses, latent sampling and image generation.

## [VQ-VAE](03_vqvae.ipynb)

Codebook lookup, straight-through estimation, and linear and convolutional VQ-VAE components.

## [Residual Vector Quantization](04_residual_vector_quantization.ipynb)

Residual quantization using multiple codebooks and a linear reconstruction model.

## Environment and status

Requires PyTorch, torchvision, NumPy, pandas, matplotlib, seaborn, scikit-learn, tqdm, and celluloid for animation cells. Examples use MNIST. Check dataset paths and download flags before running.

Open the notebook in JupyterLab or a suitable GPU notebook environment and inspect its configuration before execution. These are learning implementations; some cells are incomplete or require corrections. See [validation notes](../VALIDATION.md).

Original upload titles are recorded in [SOURCES.md](../SOURCES.md). Exact tutorial/repository attribution and the distinction between reproduced code and personal extensions remain to be documented by the author.
